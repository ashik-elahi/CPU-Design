## Designing CPU based on following requirements    
    1. Word Size of CPU: 5
    2. ALU Operations: XOR, ADD, ROL
    3. Register Number: 3
    4. Size of RAM: 7
    5. Word size of ISA and RAM: 15
    6. CPU Instructions: Register Mode, Immediate Mode, Branching Mode(JMP, JLE)
